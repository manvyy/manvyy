## 🚀 Featured Projects

### 🎬 Sentiment Analysis for Movie Reviews

A supervised NLP project for classifying sentiment in **50,000+ IMDB movie reviews**.

- Preprocessed text with **NLTK** and represented reviews using **TF-IDF**.
- Built classification models using **Logistic Regression, SVM, and Naive Bayes**.
- Evaluated and tuned models with accuracy, precision, recall, confusion matrices, and ROC curves.

**Built with:** Python · Scikit-learn · NLTK · Pandas · IMDB Dataset

### 🏫 CampusCare — Complaint Management System

A multi-role application for managing campus complaints from submission through resolution and escalation.

- Designed workflows for **students, mentors, wardens, IROs, and administrators**.
- Implemented **PHP REST APIs, JWT authentication, and role-based access control**.
- Used **MySQL** to manage complaint lifecycles, remarks, and role-specific actions.

**Built with:** HTML · CSS · PHP · MySQL · REST APIs

### 🖼️ Single Image Super Resolution using CNN & GAN

A deep learning project that reconstructs higher-resolution images with **4× upscaling**.

- Developed and trained **CNN/SRGAN-based models** with adversarial and perceptual loss.
- Created paired image training pipelines with **OpenCV**.
- Evaluated reconstructed images using **PSNR and SSIM**, comparing results against interpolation baselines.

**Built with:** Python · PyTorch · OpenCV · CNNs · GANs
